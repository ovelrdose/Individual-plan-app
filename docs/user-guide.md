# Руководство пользователя

Для врачей и специалистов по физической реабилитации (ФР) ОМР № 4.

## 1. Вход и роли

Откройте адрес сервиса в Chrome, Яндекс Браузере или Edge и войдите под своим логином. Рабочий адрес — тот, что дал администратор (`omr4.clinic.local`). Если в адресе есть **«test»**, это тестовая копия для проверки новых версий: работать в ней нельзя, всё сделанное там пропадёт. Логин и первый пароль выдаёт администратор. Сменить пароль можно в меню с вашим именем справа вверху: **«Сменить пароль»**.

- После 10 неверных попыток вход блокируется на 15 минут.
- После 8 часов бездействия сессия завершается, и нужно войти заново.

Что вам можно, задаёт администратор галочками прав. Обычно права такие:

| Что можно | Врач | Специалист ФР | Администратор |
|---|---|---|---|
| Загрузить лист назначений, создать и править программу, назначения | ✓ | ✓ | ✓ |
| Отметить выбытие, восстановить пациента | ✓ | ✓ | ✓ |
| Выбрать время группы пациента на весь курс («Время групп») | ✓ | ✓ | ✓ |
| Выбрать группу бассейна, поправить время групп и тренажёров в отдельные дни | просмотр | ✓ | ✓ |
| Расписание индивидуальных: ставить, переносить, убирать | просмотр | ✓ | ✓ |
| Групповые занятия; инструкторы: состав, пары, смены, распорядок | — | ✓ | ✓ |
| Справочники: процедуры | — | ✓ | ✓ |
| Скачать карту, выгрузить расписание в Excel | ✓ | ✓ | ✓ |
| Удалить программу | — | ✓ | ✓ |
| Пользователи: добавить, права, пароль, блокировка входа; отделения; журнал выгрузок карт | — | — | ✓ |

Все сотрудники отделения видят все его программы, кто бы их ни создал.

Страницы обновляются сами: если коллега что-то поменял, вы увидите это без перезагрузки, с подсказкой «Обновлено. Автор изменений: …». Пока вы перетаскиваете пациента или вводите текст, обновление ждёт.

## 2. Индивидуальные программы

Главный экран — **«Индивидуальные программы»**. В нём есть:

- **Фильтр:** текущие (курс идёт, пациент не выбыл), завершённые, выбывшие, все.
- **Поиск:** по ФИО и номеру ИБ, регистр и «ё» не важны.
- **Сортировка:** нажмите на заголовок столбца, повторное нажатие — в обратную сторону. По умолчанию — по номеру палаты. «Состояние» ставит наверх программы с конфликтами и «требует проверки». Фильтр и поиск сортировку не сбрасывают.
- **Порядок:** по номеру палаты.
- **Состояние программы:**
  - «требует проверки» — есть предупреждения импорта или нераспознанные назначения;
  - «расписание составлено»;
  - «есть конфликты».

### 2.1. Загрузить лист назначений (врач, специалист ФР)

1. Нажмите **«Загрузить лист назначений»**.
2. Выберите файл `.docx` или старый `.doc`: это тот же лист, который вы ведёте для бумажной истории, до 5 МБ. Файл `.doc` читается на несколько секунд дольше.
   Если загружает специалист ФР, выберите в поле **«Лечащий врач»** врача пациента: он будет напечатан в карте.
3. Нажмите **«Загрузить и создать программу»**.

Что система берёт из листа:

| Данные | Откуда |
|---|---|
| ФИО, № ИБ, ШРМ, палата | Шапка листа |
| Пол | Определяется по отчеству |
| Лечащий врач | Тот, кто загрузил лист; если загрузил специалист ФР — врач, выбранный при загрузке |
| Дата начала курса | Самая ранняя дата назначения в таблице |
| Дата окончания | По ШРМ: ШРМ 3 — 11 дней, ШРМ 4 — 15, ШРМ 5 — 20, УК — 15, как ШРМ 4 (считая день поступления) |
| Назначения | Колонка «Физиотерапия» и консультации психолога, логопеда, эрготерапевта |

Диагноз и лекарственные назначения в систему не переносятся.

После загрузки сразу откроется страница программы. Всё, что нужно проверить, собрано в блоке **«Проверьте после импорта»** и подсвечено в назначениях:

- нераспознанные строки;
- разные номера ИБ в шапках;
- пол не определился;
- бассейн без указания группы.

Когда всё проверено, нажмите **«Проверено»**.

**Особые случаи при загрузке:**

- **Лист этого пациента уже загружен** (тот же ИБ или ФИО, курсы пересекаются). Система предложит:
  - **«Открыть существующую»**;
  - **«Обновить эту программу»** (см. 2.4);
  - **«Всё равно создать новую»**.
- **Пациент лечился раньше.** Система покажет прошлый курс рядом с новым листом и предложит:
  - **«Создать по новому листу»**;
  - **«Взять прошлый план»**: назначения прошлого курса, а данные пациента и даты — из нового листа;
  - **«Это другой пациент»** — для однофамильца.

Если листа нет, программу можно создать вручную: **«Создать вручную»**.

### 2.2. Страница программы

На странице программы есть:

- данные пациента и курса: ФИО, ИБ, палата, ШРМ, даты, врач;
- назначения;
- расписание пациента;
- кнопка **«Скачать карту»**.

**Данные пациента и курса** правит врач. Дату окончания можно поменять, чтобы продлить курс или закончить его раньше. После ручной правки она больше не пересчитывается сама.

**Назначения** — таблица только для чтения, отменённые строки свёрнуты внизу. Чтобы изменить назначение, нажмите на строку: справа откроется панель.

- **В панели можно поменять:** процедуру (для нераспознанной строки), длительность, раз в день, даты назначения и отмены, «в карту». Время группы здесь не выбирается — оно в блоке «Время групп» расписания пациента; выбранное время видно в строке назначения («в 11:15»).
- **«Отменить с завтра»** — процедуру больше не проводят. Строка остаётся в карте, а следующие даты заштриховываются.
- **«Удалить»** — строка исчезнет и из карты. Используйте, только если строка попала по ошибке.
- **«Добавить назначение»** — новая строка.
- **Выбор процедуры.** Начните вводить название или синоним — появятся подсказки. Нажмите на нужную или **Enter**, чтобы выбрать первую. Чтобы выбрать другую процедуру, нажмите крестик рядом с выбранной.
- **Порядок строк в карте** меняется перетаскиванием строк таблицы.

**Расписание пациента:**

- **Группы ЛФК, группы ДС, бассейн и тренажёры** система ставит сама на весь курс и пересобирает после каждого изменения назначений или дат.
- **Индивидуальные занятия** берутся из расписания индивидуальных на сегодня и завтра (раздел 3). Над календарём видно, где пациент стоит в эти дни. Если он попал в «Не распределены», строка красная.
- **Выделение в календаре курса:**
  - жёлтым — время не как обычно;
  - красным — занятие не поставлено;
  - «…» — расписание на этот будний день ещё не составлялось.
- **В день поступления и в день выписки занятий нет.**
- **Время групп.** Если у группы несколько занятий в день (например, «ДС: острая спина» в 8:15 и 16:30), время на весь курс выбирают в блоке **«Время групп»** — врач или специалист ФР:
  - пока время не выбрано, система ставит группу сама, и строка подсвечена жёлтым: «время выбрано автоматически (8:15) — выберите»;
  - выберите время в списке и нажмите **«Выбрать»**; вариант «— авто —» возвращает автоматический выбор;
  - если выбранное время совпало с индивидуальным занятием в уже составленном расписании на сегодня или завтра, выбор сохраняется, а индивидуальное уходит в «Не распределены» — система напишет, какое именно («22.10: индивидуальное в 11:10 (Соколов) пересеклось с группой…»); поставьте пациента в расписании заново;
  - время «в 15:00» из листа назначений уже выбрано — менять его не нужно;
  - если у группы одно занятие в день, выбирать нечего, и строки в блоке нет.
- **«Переставьте в расписании».** Любое изменение на странице программы, после которого группа легла на индивидуальное в расписании на сегодня или завтра (выбор времени или группы бассейна, добавление, правка, отмена и возврат назначения, правка и возврат занятия), показывает над расписанием пациента жёлтый список таких занятий. Пациент уже в «Не распределены» — поставьте его в расписании заново.
- **Группа бассейна.** Если врач написал просто «Бассейн», специалист ФР сначала выбирает в блоке «Время групп» группу бассейна, затем время. Пока группа не выбрана, строка красная. Смена группы сбрасывает выбранное время.
- **Своё время для группы или тренажёра.** Специалист ФР может нажать на время и поставить другое. Такое занятие закрепляется значком 📌, и подбор его больше не меняет. **«Открепить»** возвращает подбор.

### 2.3. Выбытие и восстановление

- **Выбытие.** Если пациент закончил раньше срока, нажмите **«Выбыл»** и выберите причину: досрочная выписка, отказ, перевод, самовольный уход, другое. С указанной даты у него нет занятий, и он уходит из расписания. Данные и назначения выбывшего доступны только для просмотра. В карте даты после выбытия заштрихованы, рядом с палатой написано «выбыл ДД.ММ».
- **Восстановление.** Пока плановый курс не закончился, пациента можно вернуть кнопкой **«Восстановить»**. Занятия подберутся заново с сегодняшнего дня, и в завтрашнее расписание пациент встанет сам. В сегодняшнее его ставит специалист ФР.
- **Повторный курс.** На странице завершённой программы есть кнопка **«Повторный курс»**: она создаёт новую программу. По умолчанию назначения берутся из прошлого курса. Процедура, которую с тех пор убрали в архив справочника, придёт нераспознанной строкой — выберите замену.

### 2.4. Обновить из новой версии листа (врач)

Если врач поправил лист в Word, загружать программу заново не нужно:

1. На странице программы нажмите **«Обновить из листа»**.
2. Выберите файл и нажмите **«Загрузить и показать изменения»**.
3. Посмотрите, что изменится: «было → стало» по шапке и по каждому назначению.
4. Нажмите **«Применить»** или **«Отмена»**.

Что произойдёт при обновлении:

- **Лист важнее правок в вебе:** длительность, частота, даты и порядок берутся из листа.
- **Строки, которых больше нет в листе:**
  - если процедура уже начата, она отменяется с завтрашнего дня;
  - если ещё не начата, строка удаляется.
- **Не меняются:** прошедшие занятия, группа бассейна и место пациента в расписании.
- **Время группы:** если в новой версии листа у группы нет времени, выбранное на странице программы время остаётся; если указано другое («Колено в 15:00»), оно заменит выбор — это видно в «было → стало».

### 2.5. Карта

**«Скачать карту»** выгружает файл `.xlsx` по шаблону ШРМ 3, 4 или 5 (УК — по шаблону ШРМ 4). Откройте его в MS Excel и распечатайте с двух сторон листа А4: на лицевой стороне — расписание, логотип, пациент (ФИО и крупно — палата), врач и «Уважаемый пациент!», на оборотной — таблица дат. Разрыв страницы и масштаб уже заданы в файле, в окне печати менять их не нужно; включите двустороннюю печать с переворотом по короткому краю (лист альбомный — переворачивается как страница книги).

- В верхнем блоке — типичный день: время, процедура, место. Пустые строки с временем — окна пациента.
- Индивидуальное занятие берётся из ближайшего расписания (сегодня, иначе завтра). Поэтому новую карту лучше печатать, когда пациент уже стоит в завтрашнем расписании.
- Пометка тренажёра из расписания печатается рядом с ним («st-150 (шар)») — тоже с ближайшего дня, начиная с сегодняшнего.
- Заштрихованы дни, когда процедуры нет:
  - день поступления и день выписки;
  - дни до начала и после отмены назначения;
  - дни после выбытия.
- Если в какие-то дни время отличается от типичного, перед выгрузкой появится предупреждение со списком дат. Выгрузить карту всё равно можно.

## 3. Расписание (индивидуальные занятия)

Пункт меню **«Расписание»** — то, что на бумаге называли «шахматкой»: индивидуальные занятия всех инструкторов на один будний день.

**Как устроен экран:**

- **Колонки** — инструкторы в смене. Пара 2/2 занимает одну колонку («Паршуков/ Ким»), в ячейке работает тот, чья смена.
- **Строки** — время занятий, включая вечерние 18:00, 18:40, 19:20. Вечерние слоты есть только у инструкторов 2/2.
- **Справа** — тренажёры st-150, Имитрон и Pablo (13:00–15:00, по 15 минут).
- **Запись в ячейке** — «9п Фамилия», в конце может быть пометка (art, (шар), Мото-Л).
- **Серым** — постоянная занятость: «Метод. работа», ведение группы, БОС.
- **Над сеткой — два блока:**
  - **«Не распределены»** — пациентам не нашлось места: инструктор не вышел, всё занято, перенос невозможен;
  - **«Отменены»** — пациентов убрали из сетки вручную. Они остаются в блоке на следующие дни и сами не ставятся.

**Навигация:**

- стрелки и календарь — по прошлым будним дням;
- вперёд — не дальше завтрашнего расписания;
- кнопки **«Сегодня»** и **«Завтра»** (в пятницу — **«Понедельник»**).

По субботам и воскресеньям расписание индивидуальных не составляется: занятия в выходные ведут инструкторы 2/2 сами.

### 3.1. Как составляется само

Расписание на завтра создаётся автоматически при первом открытии системы в новый день. За основу берётся сегодняшнее:

- выписанные завтра пациенты уходят из сетки;
- остальные остаются на своих местах;
- кому место не подходит (инструктор не работает, у пациента в это время группа), тот попадает в «Не распределены»;
- новые пациенты (обычно поступившие сегодня) расставляются по свободным окнам. Сначала выбирается инструктор, у которого меньше всего пациентов: так нагрузка ложится равномерно. Если пациенту ещё не выбрано время группы, система по возможности не ставит индивидуальное на любое из занятий этой группы — чтобы время группы можно было выбрать свободно;
- два индивидуальных занятия у одного пациента не ставятся подряд;
- пациент с назначением Мото-Л или Артромот получает одно из индивидуальных в вечернем слоте.

В сегодняшнее расписание сами не ставятся даже новые пациенты: их ставит специалист ФР.

### 3.2. Ручная правка (специалист ФР)

Править можно сегодняшнее и завтрашнее расписание, прошедшие дни доступны только для просмотра.

- **Поставить пациента.** Нажмите на ячейку: откроется список. Сначала в нём «Не распределены» и «Отменены», затем все остальные; есть поиск по палате и фамилии. В одну ячейку можно поставить нескольких пациентов.
- **Перенести.** Перетащите пациента мышью в другую ячейку. Так же ставят из блоков «Не распределены» и «Отменены». Пока пациента тащат, красным подсвечено время, когда он занят другими занятиями.
- **Убрать.** Кнопка **«Убрать из сетки»** в панели ячейки: пациент попадёт в «Отменены».
- **Пометка.** В панели ячейки можно написать art, (шар) и т. п. У тренажёров — щелчок по пациенту в таблице тренажёров открывает панель с пометкой; как у индивидуальных, она ставится с этой даты и переходит на следующие дни. Пустое поле убирает пометку тоже с этой даты.
- **Тренажёры.** Под таблицей тренажёров две строки, в них у каждого тренажёра своя ячейка:
  - **«Не распр.»** (не распределены) — пациенты, которым на тренажёре не хватило места, или у них всё окно тренажёра занято группами и бассейном. Ячейка с такими пациентами красная;
  - **«Отменены»** — пациенты, у которых тренажёр сняли вручную.

  Всё делается перетаскиванием, только в своей колонке тренажёра:
  - на другое время — перенос;
  - из блока на время — постановка;
  - из сетки или из другого блока в «Не распр.» или «Отменены» — снятие.

  Любое такое действие касается **этой даты и всех следующих дней курса**. Дни, где пациент в это время занят или время меняли отдельно на странице программы, не меняются: они перечисляются в панели. Если ставите сверх вместимости или вне окна, система предупредит и попросит подтвердить. Причину можно указать, она станет пометкой, а можно оставить поле пустым. Сверх вместимости пациент тоже ставится на эту дату и все следующие дни.

  Пациент, поставленный вручную, отмечен значком булавки: система его сама не передвинет.

  Когда место освобождается (пациент выбыл, тренажёр сняли или перенесли, увеличили вместимость), ждущие из «Не распр.» встают на него сами, но **только с завтрашнего дня**, первыми — кто раньше поступил. На сегодня пациента ставит специалист. Снятых вручную (в «Отменены» или в «Не распр.») система сама не ставит.
- **Инструктор не вышел.** В панели ячейки отметьте «не работает». Его пациенты на эту дату уйдут в «Не распределены», и их нужно расставить вручную.
- **Блок на дату.** В панели ячейки можно поставить блок на этот слот, например «Метод. работа».

Если правило нарушено (пациент в это время занят, слот закрыт, два индивидуальных подряд), система не сохранит правку и объяснит почему.

Правка сегодняшнего расписания сразу переходит и на завтрашнее, если этого пациента в завтрашнем не правили отдельно.

**«Выгрузить в Excel»** — расписание на дату в `.xlsx` для печати.

### 3.3. Журнал расписания (специалист ФР)

Кнопка **«Журнал»** на экране «Расписание» открывает журнал: кто или что поставило пациента на индивидуальные и тренажёры, куда и почему. Журнал хранит записи за последние 7 дней.

Каждая строка журнала — одно изменение:
- **Когда.**
- **Пациент.**
- **Что:** индивидуальные или тренажёр.
- **Даты расписания.** Перенос тренажёра на весь курс — одна строка с диапазоном дат.
- **Было → стало.** Если у пациента два индивидуальных и изменилось одно, показывается только оно, второе — серым «без изменений: Волков 9:10».
- **Кто:** сотрудник и его действие («Перенос в расписании», «Добавлено назначение», «Лебедева не работает 07.10») или система («Составлено расписание на 07.10», «Освободилось место на тренажёре — ждущий встал сам»).
- **Почему.** Для решений системы — кратко, почему пациент встал именно туда или не встал и что мешало, например:
  - «автоматически к Соколов в 10:00 — у колонки наименьшая загрузка (3 пац.), самое раннее подходящее время; раньше мешало: пациент занят: Эрго 9:00»;
  - «Волков в 9:10 не работает — к напарнику Лебедева»;
  - «не поставлен: 13:00–14:45 — мест нет (3 из 3)».

  Для правки сотрудника — подтверждённые нарушения и указанная причина.

В журнал попадают только настоящие изменения. Пересчёт, после которого всё осталось на месте, не записывается. Перенос пациента «как вчера» в новое расписание тоже не записывается.

Фильтры: дата расписания, пациент (фамилия или палата), что (индивидуальные или конкретный тренажёр), кто (система или сотрудники).

У пациента в блоках «Не распределены» / «Отменены» и по щелчку по пациенту на тренажёре в панели есть **«История за неделю»**: последние записи и ссылка на весь его журнал.

### 3.4. Публичное расписание

По адресу `/board/` расписание открывается без входа, только для чтения, и только из сети клиники. Его можно вывести на экран в коридоре или открыть на компьютере инструкторов.

## 4. Групповые занятия (специалист ФР)

Пункт меню **«Групповые занятия»** — вкладка на каждый **раздел** групп (сначала «ЛФК», «ДС», «Бассейн»; число — сколько в разделе действующих занятий) и последней **«Тренажёры»**. Расписание групп одинаковое каждый день недели.

Во вкладке раздела — таблица: группы и их времена (все времена одной группы рядом; у группы с несколькими занятиями в день — пометка «занятий в день: N»). Таблица только для просмотра: **шестерёнка** у группы открывает окно правки: слева поля группы, справа её времена. Окно закрывается крестиком, «Отменой», клавишей Esc или кликом мимо окна. Внизу таблицы — свёрнутый блок **«В архиве (N)»**: удалённые группы и времена, которые уже использовались.

**Разделы.** «Новый раздел» — справа от вкладок, «Раздел» во вкладке — переименовать, сменить порядок или удалить. У раздела есть **поведение** — как его группы ведут себя в расписании:

| Поведение | Что значит |
|---|---|
| Ведёт инструктор | Группу может вести инструктор ЛФК («кисть» «Ведение группы» в «Распорядке»): занятие занимает его ячейку в расписании. Как группы ЛФК |
| Без инструктора | На расписание инструкторов не влияет; в листе назначений распознаётся последней. Как группы ДС |
| Бассейн | Из таких групп выбирают группу для назначения «Бассейн» без уточнения |

Поведение можно поменять только у пустого раздела, удалить — тоже только пустой (группа в архиве считается).

**Новая группа** — кнопка во вкладке раздела, форма открывается в окне. Заполните название, «как печатается в карте» (пусто — как название; если название длиннее 60 символов, подпись обязательна), синонимы — как группу пишут в листах назначений (по одному в поле, «добавить синоним» — ещё поле), длительность, место, отделение («Общая для центра» или ваше отделение) и сразу одно или несколько времён занятий («ещё время»). Все занятия получают длительность группы. Название не должно повторяться в отделении (без учёта регистра), время — в списке; занятие должно заканчиваться до полуночи.

**Окно группы.** Сверху — поля группы и «Сохранить». Перенести группу можно только в раздел с тем же поведением — иначе заведите новую группу. Ниже — **время занятий**: у каждого времени можно поправить начало, длительность и место (галочка — сохранить) или удалить его (корзина); «+ время» добавляет новое. Внизу — «Удалить группу».

**Удаление и архив.** После «Удалить» окно сначала спросит подтверждение:
- время или группа **ни разу не использовались** (ни одного занятия пациента, назначения, распорядка или блока инструктора) — удаляются совсем, группа — вместе с временами;
- **уже использовались** — уходят **в архив**. Окно заранее назовёт, сколько текущих программ это затронет. Дальше — как раньше при выключении: расписание текущих пациентов пересобирается, выбранное время сбрасывается, закреплённые на это время занятия снимаются, «Ведение группы» у инструкторов заканчивается сегодня. Группа в архиве пропадает из поиска процедур, из распознавания листа назначений, из выбора группы бассейна и из «Ведения группы», все её времена тоже уходят в архив; у назначения появляется красное «у группы нет занятий» — замените назначение.

Из блока «В архиве» группу или время можно открыть шестерёнкой и нажать **«Вернуть из архива»**. У группы возвращается только сама группа: её времена остаются в архиве, верните нужные по одному.

**Ведение группы.** Если время или группа ушли в архив либо время перенесли так, что оно уходит из слота инструктора, «Ведение группы» на него в «Распорядке» заканчивается сегодня: с завтрашнего дня слот инструктора свободен, разовые блоки ведения на будущие даты убираются. Окно покажет, у кого освободился слот. Названия разделов и групп сравниваются без учёта регистра: «ДС» и «дс» — одно и то же.

**Тренажёры** — так же: шестерёнка у тренажёра открывает окно правки: название, подпись в карте, синонимы, окно работы, шаг, длительность и вместимость. **«Новый тренажёр»** открывается в том же окне — тренажёр сразу можно назначать. **«Удалить тренажёр»** — с подтверждением: ни разу не использованный удаляется совсем, использованный уходит в архив вместе со своей процедурой (у текущих пациентов занятия на нём снимаются, в программе — красное «тренажёр выключен»); из блока «В архиве» его можно вернуть.

После любого сохранения расписание текущих пациентов пересобирается само, окно покажет, у кого оно изменилось:
- **Перенесли время** (например, с 11:15 на 11:30) — пациенты, которым было выбрано это время, переходят вместе с ним.
- **Время ушло в архив** — выбор этого времени у текущих пациентов сбрасывается (у завершённых курсов и выбывших выбор остаётся как был), группа ставится автоматически, на странице программы снова жёлтое «выберите».
- **Добавили время** — у пациентов этой группы появляется выбор: время не меняется, но на странице программы появляется жёлтое «выберите».
- Занятия, закреплённые вручную на старое время, снимаются, и группа ставится по новому расписанию; если группа легла на индивидуальное в расписании на сегодня или завтра, пациент уходит в «Не распределены».

## 5. Инструкторы (специалист ФР)

Всё об инструкторах — в меню **«Инструкторы»**, на одной странице с вкладками:

- **«Состав и смены»** — календарь месяца: строки — инструкторы (напарники 2/2 рядом), ячейки — рабочий или нерабочий день. Клик по ячейке меняет день (больничный, отпуск, подмена). Если инструктор перестал работать, его пациенты уходят в «Не распределены».
  - Шестерёнка у фамилии — **карточка**: фамилия «как в расписании», ФИО, напарник по 2/2 (напарник получает пару автоматически), порядок колонок в расписании и **шаблон смены** — 2/2, 5/2 или каждый день, первый рабочий день цикла и с какой даты действует (прежний шаблон закончится накануне). Шаблон меняется, только если вы его изменили; ниже видны все его периоды.
  - **«Новый инструктор»** — над календарём; шаблон смены можно задать сразу. Без шаблона инструктор не работает ни в один день.
  - **«Удалить»** — в карточке: ни разу не работавший удаляется совсем, работавший уходит в архив — свёрнутый блок «В архиве» под календарём, оттуда же «Вернуть из архива».
- **«Распорядок»** — что инструктор делает в слоте каждый рабочий день: «Метод. работа», ведение группы, БОС, прочее.
  1. Выберите вид и как ставить: **постоянно с даты** или **только на эту дату**.
  2. Нажмите на ячейку. Повторный клик тем же видом снимает отметку.

  Распорядок ставится только в часы смены: 2/2 — 8:00–20:00, остальные — 8:00–17:00. В слоты с распорядком пациенты не ставятся.
- **«Загрузка»** — сколько индивидуальных занятий провёл каждый инструктор за период.

## 6. Справочники (специалист ФР)

Меню **«Справочники»**: вкладки «Процедуры», «Сетка слотов» (только просмотр), у администратора — ещё «Журнал выгрузок карт». Таблицы — только для просмотра; запись меняют кнопкой с шестерёнкой — откроется окно. **«Новая процедура»** — кнопка над таблицей. Инструкторы — в своём разделе (раздел 5).

- **Процедуры** — всё, кроме групп (группы — в «Групповых занятиях»). Фильтр по виду и поиск по названию и синонимам. В окне: название, подпись в карте, синонимы (как процедуру пишут в листе назначений — «добавить синоним» даёт ещё поле), вид, длительность, место, отделение. У процедуры, которую уже назначали, не меняются вид, признаки («Бассейн» без группы, вечернее индивидуальное) и отделение — для этого заводят новую. Новый тренажёр заводят в «Групповых занятиях» → «Тренажёры» (там же его окно и вместимость).
- **Удалить** — в окне, с подтверждением: ни разу не использованная запись удаляется совсем, использованная уходит в архив (блок «В архиве» внизу таблицы, оттуда — «Вернуть из архива»). Инструктор в архиве с сегодняшнего дня пропадает из смен и расписания, его пациенты на сегодня и завтра уходят в «Не распределены», напарник по 2/2 остаётся один. Индивидуальное занятие, пока оно назначено текущим пациентам, в архив не уходит.
