## Как писать код
- Стек: Python 3.12, Django 5.2 LTS, PostgreSQL 16, шаблоны Django + HTMX + Alpine.js, Bootstrap 5 из `static/vendor/` (без CDN), openpyxl, django-simple-history.
- Доменная логика (`domain/`, `apps/cards/xlsx/`) — чистый Python без импортов Django: dataclass на входе, результат на выходе.
- Права и бизнес-правила проверяются в сервисах (`services.py`) через `apps/accounts/access.py` (`require_role`, `departments_for`). Представления тонкие. Чужое отделение → 404.
- Целостность — в БД: ограничения, уникальные индексы, `ExclusionConstraint`, `select_for_update` там, где возможна гонка.
- Модели, которые перечислены в NFR-5, получают `HistoricalRecords()`. Изменения, которые должны попасть в журнал, сохраняй через `save()`, а не `queryset.update()`.
- Удаление используемых записей запрещено: `on_delete=PROTECT` и флаг `is_active`.
- Даты и время занятий — «наивные» `DateField`/`TimeField`. В xlsx — настоящие значения Excel с форматом.
- Идентификаторы — на английском. Комментарии, docstring, тексты интерфейса и ошибок — на русском. Комментарий объясняет «почему» и ссылается на требование (`TZ.md, FR-XXX-N`).
- Ошибки для пользователя — отдельные исключения с понятным русским текстом, без 500.
- Аннотации типов в сигнатурах обязательны. Длина строки 100.
- Новая зависимость — только с точной версией в `pyproject.toml` (`[dependency-groups]`).
- Миграции создавай `makemigrations` и проверяй `makemigrations --check`. Пиши их руками только для данных.

## Тесты
- Каждая функция сдаётся с тестами в `tests/<app>/`: pytest + pytest-django на настоящем PostgreSQL. Общие фикстуры — в `tests/conftest.py`.
- Только обезличенные данные. Реальные ФИО и диагнозы из `primary_docs/` в тесты не попадают.
- Покрытие `domain/`, `apps/cards/xlsx/`, `exchange/` — не ниже 90 %. Для сервисов — ключевые сценарии и права.

## Перед сдачей
```bash
.venv/bin/ruff format . && .venv/bin/ruff check .
.venv/bin/python manage.py makemigrations --check --dry-run
.venv/bin/pytest -q
```
Всё должно быть зелёным. Не коммить: коммиты делаются только по просьбе владельца.
